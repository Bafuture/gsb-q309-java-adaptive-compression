## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

我们的数据块特性差异很大，用同一种压缩算法要么太慢要么压不动，希望按块特性自动选。请从零实现一个压缩算法自适应选择组件。仓库目前只有一个空的 Maven 工程（pom.xml 只声明 JUnit 5 与 AssertJ）。要求：1) 支持至少三种压缩策略（例如快速低压缩比、平衡、高压缩比），各用可插拔实现表示；2) 支持按块特征选择：依据重复率、熵估计与块大小选择策略，需说明特征计算方法；3) 支持采样决策：对超大块只采样一部分估计特征，避免先压缩再决定；4) 正确性：任何策略下解压结果必须与原始数据一致，需对所有策略统一验证；5) 支持自适应反馈：记录每种策略的实际压缩率与耗时，据此调整后续选择阈值；6) 支持每块记录所用策略标识，解压时按标识还原；7) 提供统计：各策略使用次数、平均压缩率与总耗时，并与固定策略方案对比；8) 测试覆盖策略选择、采样决策、解压正确性、反馈调整、策略标识还原与对比数据；`mvn -q verify` 一条命令跑通。
